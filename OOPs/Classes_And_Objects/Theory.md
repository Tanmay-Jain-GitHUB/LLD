# Classes And Objects

## 1. Class
- A class is a collection of objects. 
- It is a blueprint for creating objects.
- Defines object attributes and methods.

### Implementation notes:
- \_\_init\_\_ : consturctor method that runs automatically when object is created.
- self : reference to current object.

## 2. Object
- It is an instance of a class.
- Represents a specific implementation of the class.
- Consists of 
    - State : represented by attributes.
    - Behaviour : represented by methods, reflects response of object to other objects.
    - Identity : gives a unique name to an object.
